# zeus-uptime
Monitor externo (GitHub Actions, a cada 10 min) dos endpoints públicos da Torque e do site da Zeus.
Falha = e-mail automático do GitHub. Sem segredos neste repositório.
Atenção: o GitHub desliga agendamentos de repositórios públicos sem commit por 60 dias; o commit mensal de `keepalive` evita isso.
